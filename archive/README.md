# Archive

These scripts are historical. Each one starts with `#requires -Version 99.0` and will not run on Windows PowerShell 5.1 or PowerShell 7.

Do not deploy them. Use `IIS_Cert_Auto_Package` after the 2026-10-29 security fixes, or the .NET port `iis_cert_automation-dotnet`.

Internal host names that used to be hard-coded here have been replaced with placeholders.
